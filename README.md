# To Do Lost

This is a simple To Do List application that will allow users create and manage tasks.

The application is built with Java Script and React

# Installation instructions

1. Clone the repository:
got clone https://github.com/annaUniversal/react-toDoLost.git

2. Navigate to the progect directory
cd react-toDoLost

3. Install the project dependecies
npm install

# Run the development server

To start developement server, run following

npm run dev

When the server starts, open the USL, lisplaied in the terminal

http://localhost:5173/
